Ch. 01 The Opportunity

Why build an outbreak inside a game?

SHIP‑DDM trainees only get to investigate a real outbreak a handful of times before it matters. This gives them a sandbox — and gives the network a reason to keep coming back.

01 · Test Yourself

Rehearse the full cycle

Case definition, cleaning, descriptive and analytic epi, a 2×2 table, source-tracing, risk communication. Tier 1 PGCFE Field Epidemiology covers five modules over 18–24 months (intro to epi & field epi, health info systems, outbreak investigation & response, HIS data management, and system-improvement). This game reinforces that core outbreak response module.

02 · Stay Connected

A reason to log back in

This self-contained game gives a replayable, interactive touchpoint between those classroom sessions.

03 · The 30th

Built for the anniversary

PPHSN turns 30 this cycle. A self-contained, key-free game that runs on any laptop at a country-day booth or a regional meeting is exactly the kind of centrepiece a celebration needs.

A personal note — this is something I've wanted to build for a long time and never had the runway for. Generative AI is what actually let me walk the whole path — from a case-definition spreadsheet to a playable, scored, ten-room escape game — in the time this course gave us. That's the real opportunity: not just a training tool, but proof that a small team can now ship something this specific.

Ch. 02 The Voyage

Course modules, put to work

The build leaned on five of the six course weeks. Data analytics and chatbots/agents carry the most weight; the rest shape how it's delivered and felt.

Week 2Data analytics

The whole game is graded off real spreadsheet logic

COUNTIF/COUNTIFS, de-duplication, completeness checks, MEDIAN, attack rate, case-fatality ratio, sensitivity / specificity / PPV from a 2×2, and relative risk from a cohort — computed once from three published CSVs and enforced with tight tolerances, so every room has exactly one correct answer.

line listlab resultscohort data
Week 4Chatbots / agents

The Field Advisor coaches method, never the answer

A self-contained, keyword-matched knowledge base that explains how to compute RR or what PPV means — without ever handing over a room's answer. Costs +20s per question, needs no API key, and runs fully offline on GitHub Pages.

no API keytime-penalised
Week 3Deep research & text analysis

Room 9A / 9B: infodemic management

Players sort true corrections from rumour, then write a prompt for a community risk-communication script. The prompt is graded against a deterministic 7-point rubric — audience, format, corrected facts, protective actions, trusted messengers, tone, plain language.

Week 1Websites & documents

One file, zero infrastructure

The entire game — datasets, PPHSN logo, and answer key logic — ships as a single self-contained index.html. No build step, no server, deployable straight to GitHub Pages.

Week 6Design, images & video

An identity borrowed honestly

Palette and logo drawn from the PPHSN / Pacific Community identity — deep ocean navy, lagoon turquoise, Pacific coral for alert states — completely overhauled to present a clean, airy, highly accessible interface.

Ch. 06 Reflection & Next Steps

What's honest about where this stands

Static and key-free by design — which is exactly what makes it deployable anywhere, and exactly where its limits sit.

▲ Current limitations

  • The leaderboard saves to localStorage — per device, not shared across a cohort.
  • The Field Advisor is a scripted, keyword-matched coach, not a live model — it can't handle a genuinely novel question.
  • One scenario, one language (English), one disease pair (dengue / leptospirosis).

● Where it goes next

  • Live LLM Integration for Prompt Engineering: Replacing the deterministic grading rubric in Room 9B with a live, sandboxed Large Language Model. This will allow for dynamic, context-aware evaluation of risk communication prompts, giving trainees highly specific feedback on tone, empathy, and strategic reasoning rather than just checking off keywords.
  • Using a lightweight backend (like a Cloudflare Worker) to securely proxy API calls, keeping the game accessible while upgrading the intelligence of the evaluation.
